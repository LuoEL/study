1. 数据操作
x = torch.arange(12)    #创建一个行向量，包含以0开始的前12个整数，它们默认创建为浮点数
x.shape                 #shape属性来访问张量（沿每个轴的长度）的形状
x.numel()               #查询张量中元素的总数
X = x.reshape(3, 4)     #把张量x从形状为（12,）的行向量转换为形状为（3,4）的矩阵
torch.zeros((2, 3, 4))  #创建一个形状为（2,3,4）的张量，其中所有元素都设置为0
torch.ones((2, 3, 4))   #创建一个形状为(2,3,4)的张量，其中所有元素都设置为1
torch.randn(3, 4)       #创建一个形状为（3,4）的张量。 其中的每个元素都从均值为0、标准差为1的标准高斯分布（正态分布）中随机采样
tensor = torch.normal(mean=2.0, std=0.5, size=(3, 4))       #均值2，标准差0.5
torch.tensor([[2, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])    #为所需张量中的每个元素赋予确定值

+，-，/，*，**都是利用广播机制，x**y意思是x的y次方
torch.exp(x)    #e的x次方
torch.cat((X, Y), dim=0), torch.cat((X, Y), dim=1)  #0是按行连结，1是按列连结
X == Y  #相等为True，不一样为False
X.sum()                 #对张量中的所有元素进行求和，会产生一个单元素张量
